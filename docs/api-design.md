# Интерфейсы и интеграции

## Текущий интерфейс

Реализованный интерфейс - это Excel/VBA, вызывающий Python через `xlwings`.

| Вызов | Python-точка входа | Назначение |
| --- | --- | --- |
| Проведение заказов | `inventory_app.orders.sync_order_operation.main()` | Считывает листы заказов, обновляет SQLite и Excel. |
| Синхронизация ручных изменений | `inventory_app.manual_changes.sync_changes.main()` | Синхронизирует товары, поступления и остатки. |
| Управление товарами | `inventory_app.products.*.main()` | Добавляет, отключает или восстанавливает товарные позиции. |
| Закрытие сезона | `inventory_app.season_management.season_service.main()` | Вызывается макросом `CloseSeason.bas`; создаёт архив и новый сезон. |

## Контракт данных внутри системы

Python читает из Excel товарные идентификаторы, название, цену, размер, остатки, листы заказов и столбцы поступлений. Результаты фиксируются в SQLite, после чего Excel получает актуальное значение столбца «Наличие» и служебные заголовки партий/заказов.

## Планируемые, но не реализованные интеграции

Telegram-бот, REST API и LLM/RAG-компонент отсутствуют в кодовой базе. До их реализации здесь нельзя публиковать URL, HTTP-методы или JSON-контракты как существующий API. При старте такой работы рекомендуется сначала согласовать отдельную спецификацию API и модель авторизации.
