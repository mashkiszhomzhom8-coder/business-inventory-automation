# Требования

## Назначение

Система автоматизирует учёт товаров и операций в малом бизнесе. Excel используется как пользовательский интерфейс; SQLite хранит согласованное состояние и историю операций.

## Реализованные функциональные требования

| Область | Реализованное поведение |
| --- | --- |
| Товары | Создание, отключение и восстановление товаров; хранение названия, размера, цены, текущего остатка и статуса активности. |
| Заказы | Чтение листов заказов Excel, запись заказа и позиций в БД, списание остатков, обновление прайса и удаление успешно проведённых листов. |
| Отмена заказа | Отключение и восстановление заказов с корректировкой остатков, движений и столбцов Excel. |
| Поступления | Обработка новых и скорректированных поступлений, хранение партий и позиций, отражение движения товара. |
| Ручные изменения | Синхронизация изменений названия, размера, цены и остатков с Excel; изменения атрибутов записываются в журнал. |
| Инвентаризация | Фиксация ожидаемого и фактического остатка, разницы и движения товара. |
| Сезоны | Проверка согласованности Excel и БД, архивирование рабочей книги, открытие нового сезона и фиксация его стартовых остатков. |

## Правила целостности

- БД хранит `products.current_stock`; Excel-столбец «Наличие» обновляется из этого значения.
- Для синхронизации создаётся резервная копия Excel. При ошибке транзакция SQLite откатывается, а книга восстанавливается из копии.
- В БД может быть только один активный сезон.
- Перед закрытием сезона проверяется совпадение товаров, атрибутов и остатков в Excel и БД.
